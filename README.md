## 📁 Repository Structure & Projects

### 1. Interactive BMI & Character Simulator (`app.py` & `doraemon_world.html`)
* **Language:** Python & HTML5 Canvas / JavaScript
* **Features:**
  * Real-time BMI category computation (Underweight, Normal, Overweight, Obese).
  * Dynamic environment physics including weather, floating wind, and gym settings.
  * Customizable character traits, male/female gender styling, and movement animations.
  * Interactive controls with a manual calculation action trigger.

### 2. Student Management System (`student_management_system.py`)
* **Language:** Python
* **Features:**
  * Subject-wise marks entry.
  * Automatic total and average calculation.
  * Grade generation and subject-wise performance analysis.
  * Remark generation.

### 3. Practical Lab & Algorithm Scripts
* **`day1_algorithm.py`**: Introductory algorithmic problem-solving script.
* **`first_submission.py`**: Initial practical lab submission.
